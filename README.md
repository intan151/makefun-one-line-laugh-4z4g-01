A deterministic Python entry for the make.fun competition "One Line, One Laugh". It writes one funny line — 101 characters, a single line — about a standing desk that changed nothing.

> I bought a standing desk to sit less — now I just stand still and scroll, like a very upright potato.

## Run it

```sh
python3 main.py
```

## How it works

`main.py` (Python 3.13 standard library only, no network, no randomness) validates the line (1–140 characters, one line, not only whitespace) and writes it to `/output/entry.txt`. Run it with `python3 main.py`.

Two runs produce byte-identical output (sha256 `bbed9f743e729453d281b05490771bec524fecb4483e96f4c70d1e77bbdd9aea`).
